# Phase 01 Plan 01: ML Feature Importance & Ablation Study

## Goal

Measure the importance of the 6 features used in `ml_predictor.py`'s
ensemble model, run single-feature ablation, exhaustive subset search,
and produce a clear recommendation on which features to keep or drop.

## Feature Index

| # | Name           | Description                                       |
|---|----------------|---------------------------------------------------|
| 0 | last_gpa       | Most-recently-completed semester GPA              |
| 1 | prior_cgpa     | Credit-weighted CGPA of all prior semesters       |
| 2 | gpa_momentum   | last_gpa − prior CGPA (clipped ±2)                |
| 3 | difficulty     | Batch/dept average GPA for the target semester    |
| 4 | backlog_count  | Backlogs entering target semester (clipped 0–6)   |
| 5 | target_sem     | Which semester is being predicted (1–8)           |

## Tasks

### Task 1 — Fix Unicode & load real data
**File:** `analyze_features.py`
**Goal:** Script runs to completion in Windows CP-1252 terminal.
- Replace all Unicode symbols with ASCII equivalents
- Replace `get_deep_student_analysis` call with correct DB API:
  load all students from every profile, call `compute_deep_analysis`
  on each student's raw exam records, populate `deep_cache`,
  then call `build_training_data`.
- Print sample count and bail out clearly if < 10 samples.

### Task 2 — Pearson correlation + MDI importance
**File:** `analyze_features.py`
**Goal:** Functions `compute_correlations` and `compute_mdi_importance`
work and print clean ASCII tables.

### Task 3 — Permutation importance (RF)
**File:** `analyze_features.py`
**Goal:** `compute_permutation_importance` runs; prints sorted table.

### Task 4 — Single-feature ablation (drop-one CV)
**File:** `analyze_features.py`
**Goal:** `single_feature_ablation` runs full TimeSeriesSplit CV for
each of the 6 drop-one subsets and prints delta MAE/R2.

### Task 5 — Exhaustive subset search (sizes 2–5)
**File:** `analyze_features.py`
**Goal:** `best_subset_search` iterates all C(6,k) combos, prints
top-5 per size.

### Task 6 — Summary recommendation block
**File:** `analyze_features.py`
**Goal:** Print a clean ASCII recommendation: list drop candidates
(delta MAE < 0), critical-keep features, and best overall subset vs baseline.

## Acceptance Criteria

- `python analyze_features.py` exits 0
- No UnicodeEncodeError on Windows CP-1252
- All 6 sections print (stats, baseline, correlation, MDI, permutation,
  ablation, subset search, summary)
- Delta values correctly reflect CV performance change
