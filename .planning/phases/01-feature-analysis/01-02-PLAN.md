# Phase 01 Plan 02: Implement & Test Sequence-Aware Methods without PyTorch

## Goal
Implement and test the three proposed methods using standard libraries and scikit-learn on the 2,345 training samples:
1. Separate models trained per target semester.
2. Feature engineering: weighted moving average (decay), slope of GPA trend, volatility (std).
3. Lag features (gpa_lag1, gpa_lag2, gpa_lag3) with fallback/mean imputation.
Measure final performance (MAE, RMSE, R²) and compare with the baseline.

## Tasks
### Task 1 — Implement Method 2 & 3 Feature Engineering
Add weighted decay GPA, GPA trend slope, volatility std dev, and lag features to a new feature engineering pipeline function.
### Task 2 — Implement Method 1 Semester-Specific Models
Implement the multi-model architecture where we train separate models (one per target semester t in 2..8).
### Task 3 — Evaluate Performance
Compare performance of the new model against the baseline, printing MAE, RMSE, and R².
